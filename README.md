Token Radar ranks pre-token protocols by implied value. It scores every protocol in a sealed snapshot with the `radar-2` model (category multiples, 7-day momentum, runway, chain breadth) and renders a 40-protocol watchlist board with a filterable dashboard — no hard-coded list, no network, deterministic output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
